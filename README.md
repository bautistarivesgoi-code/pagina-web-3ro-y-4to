# Friv 2

Página de juegos hecha con HTML, CSS y JavaScript.

## Estructura

- `index.html`: la página
- `style.css`: estilos
- `script.js`: buscador de juegos
- `images/`: fondos, portadas y personajes

## Cómo verla

Abrí `index.html` en el navegador. Para publicarla en GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `(root)`.
